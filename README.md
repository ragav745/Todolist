# Todolist
# 📝 Todo List App

A simple and user-friendly Todo List application that helps users manage their daily tasks efficiently.

## 🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- 📋 View all tasks
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
